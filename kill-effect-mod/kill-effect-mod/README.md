# Kill Effect — мод для Minecraft 1.21.11 (Fabric)

Когда ты убиваешь другого игрока, на месте его смерти играет анимация:
вспышка, расходящееся кольцо, две спирали из душ и финальный салют со звуками.

## Как получить готовый .jar (способ без установки программ)

1. Зарегистрируйся на https://github.com (бесплатно).
2. Создай новый репозиторий и загрузи в него все файлы из этой папки
   (Add file → Upload files, перетащи содержимое папки, включая `.github`).
3. Открой вкладку **Actions** → дождись зелёной галочки у "Build mod".
4. Открой запуск → внизу **Artifacts** → скачай `killeffect-mod` (внутри `killeffect-1.0.0.jar`).

## Как установить

1. Установи Fabric Loader для 1.21.11: https://fabricmc.net/use/installer/
2. Скачай Fabric API для 1.21.11 (Modrinth или CurseForge) и положи в папку `mods`.
3. Положи `killeffect-1.0.0.jar` в ту же папку `mods`
   (Windows: `Win+R` → `%appdata%\.minecraft\mods`).
4. Запусти игру профилем Fabric.

Работает в одиночной игре и на сервере (на сервере мод нужен только серверу).

## Настройки

В `src/main/java/com/killeffect/KillEffectMod.java`:
- `EFFECT_FOR_MOBS = true` — эффект и на мобов, не только на игроков;
- `DURATION` — длительность анимации в тиках.
